# 通用AV作品评分与简介规范

> 本规范已做个人偏好脱敏，适用于大多数用户。  
> 片单推荐使用 **Excel** 格式管理（体积小、可筛选排序、易编辑）。  
> 随着片库不断积累，评分会越来越准、越来越贴合实际观感。

---

## 〇、使用指南（最高效用法）

1. **新用户第一次使用**  
   复制「二、给新用户的提示词」，把番号发给 AI。AI 会按本规范生成简介、标签和评分，并输出为可直接粘贴进 Excel 的行数据。

2. **已有 Excel 片单时**  
   把新番号 + 本规范一起发给 AI，要求「按现有 Excel 列结构追加」，即可保持格式统一。

3. **Excel 标准列结构（必须遵守）**  

   | 列名 | 说明 |
   |------|------|
   | 编号 | 连续整数，从 1 开始 |
   | 品番 | 作品番号（如 SONE-560） |
   | 分类 | 见下方「分类体系」 |
   | 推荐评分 | 0–10，保留两位小数 |
   | 简介 | 详细中文简介 |
   | 主题 | 标签，顿号分隔 |
   | 角色 | 标签，顿号分隔 |
   | 服装 | 标签，顿号分隔 |
   | 体型 | 标签，顿号分隔 |
   | 行为 | 标签，顿号分隔 |
   | 玩法 | 标签，顿号分隔 |
   | 场景 | 标签，顿号分隔 |
   | 剧情 | 标签，顿号分隔 |
   | 其他 | 标签，顿号分隔 |

4. **建议工作表**  
   - `片单`：主数据（带自动筛选）  
   - `分类统计`：各类数量与平均分  
   - `使用说明`：简短操作提示

## 一、通用评分标准（满分10分，保留两位小数）

### 评分维度与建议权重（可按个人喜好微调）

| 维度 | 建议权重 | 说明 |
|------|----------|------|
| 制作规模与完成度 | 18% | 人数规模、场景丰富度、拍摄质量、内容是否注水 |
| 性张力与エロ完成度 | 18% | 整体色气、女优投入程度、玩法丰富度、持续兴奋感 |
| 女优漂亮度 | 15% | 颜值、身材、气质、镜头表现力 |
| 女优知名度 | 12% | 是否有一线/头部女优、粉丝基础 |
| 剧情优秀度 | 12% | 故事完整度、节奏、情绪张力、沉浸感 |
| 时长与内容密度 | 8% | 有效内容占比、高光集中程度 |
| 演技与情绪表达 | 7% | 表情、喘息、高潮反应自然度与感染力 |
| 新鲜感 / 差异化 | 5% | 独特设定、少见玩法、避免同质化 |
| 系列定位与口碑 | 5% | 是否经典系列、续作稳定性、整体口碑 |

**说明**：  
以上权重为通用推荐值。用户可根据自身偏好调整。  
最终分数 = 各维度得分 × 对应权重 之和，保留两位小数。

### 参考分数区间

- **9.20 – 9.60**：业界顶级大作、超高完成度、强烈推荐  
- **8.50 – 9.15**：高质量优秀作品，值得优先观看  
- **7.80 – 8.45**：中上水准，有明显优点  
- **7.00 – 7.75**：中等水平，可按喜好选择性观看  
- **6.50 以下**：完成度一般或同质化较严重

## 五、使用建议与 Excel 操作提示

1. 新用户复制「二、提示词」，替换番号即可让 AI 输出标准行数据。  
2. 将 AI 输出的行直接粘贴到 Excel「片单」表末尾，或让 AI 生成完整 `.xlsx`。  
3. 建议开启自动筛选，并按「分类」「推荐评分」排序/筛选。  
4. 多人作品可用浅绿色行底，单体用浅橙色，评分 ≥ 9.0 可高亮。  
5. 片库越大，对女优表现、系列口碑、实际完成度的判断越准确。
